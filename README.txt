TOMMY BARBER - ملفات الرفع على GitHub
=====================================
ارفع كل الملفات والمجلدات دي في أول الـrepo (مش جوه فولدر):
  index.html  manifest.webmanifest  sw.js  icon-192.png  icon-512.png
  css/  js/  assets/

التعديل بعد كده: غيّر الملف المعني بس
  الفاتورة والكاشير -> js/pos.js        الفواتير -> js/invoices.js
  العملاء -> js/clients.js               التقارير -> js/reports.js
  الخدمات والأسعار -> js/catalog.js      الحلاقين -> js/staff.js
  المستخدمين والإعدادات -> js/users-settings.js
  شكل الفاتورة -> js/invoice-settings.js  المسح والأرشفة -> js/data-tools.js
  الألوان والتصميم -> css/theme.css       اللوجو -> assets/
بعد أي تعديل: لو غيّرت ملف css/js زوّد رقم v=5 في index.html (مثلاً v=6) وغيّر tommy-v6 في sw.js.
